# Crime Hotspot Prediction

## 📌 Overview
This project focuses on predicting crime hotspots using machine learning and spatial data analysis.

## 🚀 Features
- Crime data analysis
- Hotspot prediction
- Machine learning models (Random Forest, etc.)
- Visualization of crime-prone areas

## 🛠️ Technologies Used
- Python
- Pandas, NumPy
- Scikit-learn
- Matplotlib / Seaborn

## 📂 Project Structure
- `models/` → trained models
- `src/` → source code
- `app.py` → main application

## 📊 Methodology
- Data preprocessing
- Feature extraction
- Model training
- Prediction & visualization
